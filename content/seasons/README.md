# Season recaps

One optional markdown file per season, named `season-<N>.md` (e.g.
`season-4.md`). The content renders in the recap section of that season's page.
If a file is missing, the recap section is simply omitted.

The hard facts for a season (champions, MVP, finals bracket, captains) live in
`src/config/seasons/season-<N>.ts` — these files are just the prose.
